# Peters Township Rec — Summer Showdown 2026
Results site for the PTGSA Summer Showdown, Aug 13-16 2026 (Peterswood Park & Pleasant Valley).

- `/` — landing page linking all divisions
- `/8u/` `/10u/` `/12u/` — interactive division breakdowns (standings, results, stat leaders, team pages)
- `/cards/` — shareable result-card and team-spotlight graphics

Static site, no build step. Enable GitHub Pages (Settings > Pages > Deploy from branch > main, / root) and it's live.
